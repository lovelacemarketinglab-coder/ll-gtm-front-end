# LL GTM public frontend agent instructions

These instructions apply to AI and coding agents working in this repository.

## Repository role

This repository owns the public LL GTM website. Keep internal operating materials, prospect research, client materials, unpublished strategy, and private opportunity data out of this repository.

See `docs/SITE_FOUNDATION.md` for the current site architecture and content boundary.

## Frontend design standard

Before implementing or materially revising frontend design, read `docs/FRONTEND_DESIGN_CHECKLIST.md`.

The company-level master standard lives in the private `ll-gtm-studio` repository at `docs/FRONTEND_DESIGN_STANDARD.md`.

Apply the checklist during implementation and again before declaring visual work complete.

Do not default to generic SaaS patterns, excessive cardification, universal rounded containers, decorative gradients, or repeated component-library layouts merely because they are easy to generate.

Preserve human review for major brand direction, typography-system changes, major color changes, distinctive visual motifs, unusual interactions, and public-facing claims.

## Scope discipline

Keep changes limited to the requested objective. Do not expand the public offer, add new services, publish new claims, deploy, or make other production changes without explicit approval.

Prefer the smallest reversible change and preserve existing work unless replacement is explicitly authorized.
